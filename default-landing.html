📍 kenapa halaman ini muncul?

Domain yang lo akses nge-resolve DNS ke 209.50.50.121 tapi belum ada server_name yang cocok di nginx. Default fallbacknya adalah landing page ini.

🚀 mau di-host service lo sendiri?

Tambahin server_name yourdomain; block di /etc/nginx/conf.d/rara-nginx.conf di dalam container kali, terus docker exec kali nginx -s reload. Arahkan proxy_pass ke port app lo.

🔒 masalah security?

Domain non-registered akan kena landing page ini aja. Rara + admin panel cuma kebuka via rara.ai.id (ada host-whitelist middleware di Next.js buat defense-in-depth).
